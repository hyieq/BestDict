# App icon source

`app-icon-source.png` is the selected DI / CT speech-bubble design, generated with
the built-in image generation tool and selected by the user. It is a 1254 × 1254
RGBA PNG with a transparent background. Keep this source unchanged when encoding
platform assets.

Run `.venv/Scripts/python.exe scripts/make_icons.py` to regenerate the application
and README PNGs, multi-resolution Windows ICO, and macOS ICNS.

## Generation prompt

Use case: logo-brand. Create ONE polished app icon concept for the desktop
dictionary app DICT, delivered as a square transparent PNG. Real alpha
transparency outside the artwork; never draw a checkerboard pattern. Style:
flat, exceptionally simple, bold memorable silhouette, crisp vector-like edges,
restrained solid colors, strong small-size readability at 32–64 px. Exact
lettering: "DICT" (D I C T), no other words, no captions, no version numbers.
Design an original distinctive identity, professionally optically balanced,
centered with comfortable padding. No 3D, gradients, bevels, glass, textures,
lighting, cast shadows, mockup, device frame or presentation board. One icon only
per image.

Concept 3 — word bubble: a crisp distinctive compact speech-bubble silhouette,
one expressive angular tail and generous negative space. Exact DICT lettering
arranged in a confident compact two-line DI / CT composition inside, using thick
custom letterforms. Minimal structure, the silhouette must be distinct from the
typographic monogram and the book concepts. No enclosing app tile.
